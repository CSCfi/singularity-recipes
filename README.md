# CSC Container Recipes

Public recipe files for Apptainer (formerly Singularity) and OCI containers used on CSC HPC platforms.

---

This repository is used to host publically available files related to Apptainer and OCI containers used on CSC HPC platforms (e.g. definition files, bash scripts and files with relevant licensing details). Note that this repository should not include any files reserved for internal use at CSC.
